私隱政策

最後更新：2026-10-21

夾錢易係一個免費嘅夾錢計算機。我哋設計成唔使註冊，亦唔需要你嘅個人資料。

存喺你部機嘅資料

你輸入嘅名、金額同帳本都只會存喺你部機瀏覽器嘅本機儲存（local storage），唔會傳俾我哋。

你隨時可以喺「設定 → 備份」下載備份檔；清除瀏覽器嘅網站資料就會刪晒所有內容。

即時共享（自選）

如果你為某個帳本開啟即時共享，嗰個帳本（名稱、成員名、你填嘅收款資料同支出）會存喺 Google Firebase（Cloud Firestore），等收到連結嘅朋友可以即時睇同改。

任何有連結嘅人都可以打開同修改即時帳本，所以只分享俾信任嘅人，亦唔好輸入敏感資料。你隨時可以喺自己部機停止同步；如需要刪除網上帳本，請經 GitHub 聯絡我哋。

分享連結同 QR code

普通分享連結本身已包含帳本嘅壓縮副本，唔會上載去任何地方，但收到連結嘅人可以睇到內容。

第三方服務

當你用其他貨幣記帳，App 會由 open.er-api.com 下載匯率；同所有網站一樣，該服務可以見到你嘅 IP 地址。

「支持我哋」按鈕會打開 Ko-fi，佢有自己嘅私隱政策。

網站由 GitHub Pages 託管，可能會保留一般伺服器記錄。

Cookie 同追蹤

夾錢易唔使用 cookie、廣告或者任何追蹤。

聯絡
