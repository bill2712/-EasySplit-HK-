隐私政策

最后更新：2026-10-21

夹钱易是一款免费的 AA 计算器，无需注册，也不需要你的个人数据。

保存在你设备上的数据

你输入的名字、金额和账本只保存在你设备浏览器的本地存储（local storage）中，不会发送给我们。

你可随时在「设置 → 备份」下载备份文件；清除浏览器的网站数据即可删除全部内容。

实时共享（可选）

如果你为某个账本开启实时共享，该账本（名称、成员名、你填写的收款信息和支出）会保存在 Google Firebase（Cloud Firestore），以便收到链接的朋友实时查看和编辑。

任何持有链接的人都能打开和修改实时账本，请只分享给信任的人，也不要输入敏感信息。你可以随时在自己的设备上停止同步；如需删除在线账本，请通过 GitHub 联系我们。

分享链接和二维码

普通分享链接本身包含账本的压缩副本，不会上传到任何地方，但收到链接的人可以查看内容。

第三方服务

当你用其他货币记账时，应用会从 open.er-api.com 下载汇率；和所有网站一样，该服务可以看到你的 IP 地址。

「支持我们」按钮会打开 Ko-fi，其有自己的隐私政策。

网站托管于 GitHub Pages，可能会保留一般服务器日志。

Cookie 与追踪

夹钱易不使用 cookie、广告或任何追踪。

联系

如有问题或请求：请在 https://github.com/bill2712/-EasySplit-HK-/issues 提交 issue。
